# 03 — FPGA 工程

本目录收录数字控制侧的**完整 RTL 实现**、引脚约束模板与硬件接口定义。四个模块构成一条完整闭环链路：ADC 采集 → 2P2Z 补偿 → DPWM 调制，保护与软启动在顶层完成。

## 目录内容

| 位置 | 内容 |
|---|---|
| **`rtl/`** | 上板版完整 RTL：`dpwm_core.v`(97 行)、`adc_if.v`(110)、`comp_2p2z.v`(153)、`dpwm_top.v`(331)，说明见 `rtl/README.md` |
| **`sim/`** | DPWM 自检回归测试台：`tb_dpwm.v` + `run_sim.bat`（Vivado xsim 一键仿真），说明见 `sim/README.md` |
| **`xdc/`** | `dpwm_top.xdc` —— **上板实际使用的引脚约束**（24 条 `PACKAGE_PIN`，覆盖顶层全部端口）；`dpwm_top_template.xdc` 为早期模板，仅作参考 |
| **`接口表/1-信号接线表.md`** | **接口契约（唯一依据）**：功率板 J3 ↔ FPGA J10 的针号映射、PWM/故障/ADC/采样信号定义、供电方向与接线规则 |

## 系统规格速览

| 项 | 值 |
|---|---|
| 器件 / 工具 | Zynq-7020（`xc7z020clg400`）/ Vivado 2022.2 |
| 时基 | 板载 50 MHz → MMCM（`clk_wiz_0`）→ **200 MHz**，时间分辨率 **5 ns** |
| 开关频率 | 200 kHz（`PERIOD_CY` = 1000）|
| 占空比字长 | 11 bit，限幅 [100, 900]（10 %–90 %），初值 200（开环 20 %）|
| 数字死区 | `DEAD_CY` = 40 拍 = **200 ns**（高低侧双向；实测 200.0 ns）|
| 输出逻辑 | 严格互补，任何瞬间不得同时为高（测试台全程监视）|
| ADC 采集 | AD9226 12 bit，200 MHz ÷ 100 = **2 MHz** 采样时钟（与 PWM 同源），每周期 3 点取 2 |
| 补偿器 | 定点 2P2Z，Q14 系数，48 位累加器，10 拍多周期流水 MAC |
| 保护 | 逐周期封锁（2 拍 = 10 ns 逻辑）→ 数字链路 58 ns → 含 1 µs 滤波 ≈1.0 µs → 驱动 SD（再 +95~120 ns）|
| 时序 | 200 MHz 下 WNS **+0.581 ns** |

## 仿真（DPWM 五项回归）

```bat
cd sim
run_sim.bat        # Vivado 2022.2 自带 xsim，约 20 秒
```

当前上板版 RTL 的实测输出（2026-10-30 复跑）：**周期 5000.00 ns（200.0 kHz）/ 分辨率 +5.00 ns / 死区 200.00 ns（双向）/ 互补 2300+2300+2×200 = 5000 ns / 故障封锁正常 → 五项全部通过**。详见 `sim/README.md`。

## 依赖与未随仓库提供的内容

- **Vivado IP**：顶层实例化了 `clk_wiz_0`（50 → 200 MHz MMCM）与 `ila_0`（6 探针 / 深度 2048，调试用）。两个核的 `.xci` 配置文件**已随仓库提供**在 `ip/` 下（Vivado 2022.2，器件 `xc7z020`），用 *Add Sources → Add Existing IP* 加入工程即可；同目录还有 `build_ila.tcl`（重建 ILA 并重跑综合/实现，路径可用参数或环境变量指定）。不使用 ILA 时可注释掉 `dpwm_top.v` 中的 `u_ila` 实例。详见 `ip/README.md`。
- **引脚约束**：`xdc/dpwm_top.xdc` 是**上板实际使用**的完整约束（139 行 / 24 条 `PACKAGE_PIN` / 覆盖 13 个端口，引脚取自 ALINX 官方 AX7020 资料），可直接加入工程；`xdc/dpwm_top_template.xdc` 是早期模板（`【PIN_XX】` 占位），仅作历史参考。

> 更完整的设计推导（Buck 小信号模型、2P2Z 零极点配置、定点量化与流水线时序折中、ADC 标定与采样相位）见技术文档第 2.3 节与第 3.3 节。
