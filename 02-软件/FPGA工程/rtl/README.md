# rtl/ — 完整数字控制逻辑（上板版）

本目录是本作品数字控制侧的**最终 RTL**，即上板运行、报告与答辩中全部实测数据所对应的那一版代码。
四个 `.v` 文件均为上板工程的**原始文件（未做任何改写）**，已用 Vivado `xvlog` 复核可编译（exit 0）。
四个模块自上而下构成一条完整闭环链路：**ADC 采集 → 2P2Z 补偿 → DPWM 调制**，保护逻辑与软启动在顶层完成。

```
adc_d[11:0] ──► adc_if ──► y_adc ──► comp_2p2z ──► duty ──► dpwm_core ──► pwm_h / pwm_l
                  │                       ▲                    │
                  └── ADC_CLK(2 MHz) ─────┘   loop_en / FAULT_N ─┘        SD（驱动关断）
                            （保护、消隐、闩锁、软启动、心跳、ILA 均在 dpwm_top 内）
```

## 文件

| 文件 | 行数 | 作用 |
| --- | ---: | --- |
| `dpwm_core.v` | 97 | 计数器型 DPWM：周期 1000 计数（200 kHz）、死区 40 计数（200 ns）、限幅 [100, 900]、逐周期故障封锁、严格互补输出 |
| `adc_if.v` | 110 | AD9226 采集接口：200 MHz ÷ 100 = 2 MHz 采样时钟（与 PWM 同源、相位固定）、每周期 3 点采样取 2（多数表决）、7 拍流水延迟补偿、上电热身 |
| `comp_2p2z.v` | 153 | 定点 2P2Z 补偿器：Q14 系数、48 位累加器、10 拍多周期流水 MAC、内部状态抗积分饱和、输出限幅、软启动参考斜坡 |
| `dpwm_top.v` | 331 | 顶层：50 MHz → 200 MHz 时钟、2FF 同步、逐周期封锁 + 1 µs 数字滤波 + 2.62 ms 上电消隐 + 闩锁关断 SD、软启动、心跳灯、ILA 探针 |

设计推导（Buck 小信号模型、2P2Z 零极点配置、fc 6.98 kHz / PM 83.5°（解析，图 2-15）、定点量化与流水线时序折中）见报告第 2.3 节与第 3.3 节。

> 注：`comp_2p2z.v` 中 `REF_CODE` 那行的注释写的是「5V @ 实测分压比 0.354」——0.354 是**板内设计**分压比；本版实际用板外 220 Ω／2.2 kΩ 分压（0.2017）绕过 ADC 50 Ω 输入阻抗问题，`REF_CODE = 2453` 与该分压比对应。源文件保持上板原样，未改注释。

## 复位与启动顺序（硬件行为，务必按此操作）

本版**不能一上电就闭环**：输出为 0 时误差约 +405 码，积分器会把占空比顶到 86 %，此时再上 24 V 会造成冲击。正确顺序：

1. `loop_en = 0`（开环固定 20 %）；
2. 上 24 V，确认输出约 5 V；
3. 接回 `loop_en = 1`，闭环收敛到 5.00 V；
4. 保护误触发后按 PL 侧 `KEY1` 复位（`rst_btn_n`）。

## 引脚约束

`xdc/dpwm_top.xdc` 是**上板实际使用的引脚约束**（139 行 / 24 条 `PACKAGE_PIN`，覆盖顶层全部 13 个端口；引脚取自 ALINX 官方 AX7020 原理图与官方示例约束，不是猜的）。上板直接把这一份加入工程即可。

`xdc/dpwm_top_template.xdc` 是早期**模板**（引脚处仍是 `【PIN_XX】` 占位），仅作历史参考；实际映射以 `xdc/dpwm_top.xdc` 为准。

## 回归验证

`sim/` 下有自检测试台，一条命令验证 DPWM 的五项硬指标（周期 / 分辨率 / 死区 / 互补 / 故障封锁）。当前上板版 RTL 的实测回归输出：

```
 DPWM 验收测试台  |  周期 5000 ns  |  死区 200 ns
[ OK ] 验收1 开关周期：5000.00 ns  →  开关频率 200.0 kHz
[ OK ] 验收2 分辨率：duty+1 → 高电平 +5.00 ns（正好 1 个时钟）
[ OK ] 验收3 死区（上管关 → 下管开）：200.00 ns
[ OK ] 验收3 死区（下管关 → 上管开）：200.00 ns
[ OK ] 验收4 互补关系：上管 2300.00 + 下管 2300.00 + 2×死区(=2×200) = 5000.00 ns
[ OK ] 验收5 故障封锁：fault_i=1 → 两路同时为低
 结果：全部通过
```

此外还有三层验证（见报告 §3.3）：Python 定点模型与 RTL 位精确对拍 1100 点 0 失配；端到端 RTL 闭环仿真稳态 4.9946 V / 纹波 14.9 mV / PM 83.9°；上板实测 5.00 V、误差 0 码。
