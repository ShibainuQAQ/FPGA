# 03-EDA导出（临时工作区）

用途：放**立创EDA 导出的网表 / BOM / 源文件**，供 AI（本会话）逐网络核对接线。

## 建议导出三样（按重要性）

| 顺序 | 导出什么 | 立创EDA 里的位置 | 文件名建议 |
|---|---|---|---|
| ① | **网表（Netlist）** ← 最重要 | 菜单「导出 / Export」→「网表 / Netlist」，格式选 **Protel**（纯文本） | `网表-20261009.NET` |
| ② | **BOM（CSV）** | 「导出」→「BOM」 | `BOM-20261009.csv` |
| ③ | （可选）**源文件 JSON** | 「文件」→「导出」→「立创EDA 源文件(.json)」 | `原理图-20261009.json` |

## 放着就行

另存到这个目录（或工作区任意位置）后，跟 AI 说一句"放好了 + 文件名"，即可直接读。

## 说明

- 这些是**过程文件**，核对完可删或留档；正式交付物仍在 `01–04` 各目录。
- 网表里会有中文网络名（`24V`/`VOUT`/`ISENSE_P`…），编码 GBK 或 UTF-8 都能处理。
