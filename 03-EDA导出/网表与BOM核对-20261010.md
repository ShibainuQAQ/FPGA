### ❌ 唯一真错：No.5（C11, C15, C16）

| 列 | 内容 |
|---|---|
| Comment / Value | `470uF` |
| **Footprint** | **`C0805`**（0805 贴片） |
| **Manufacturer Part** | **`HGC0805R5106K250NSLJ`**（Chinocera 华瓷） |
| **Supplier Part** | **（空）** |

**问题：**

1. **0805 物理上装不下 470µF** —— 0805 MLCC 的上限也就几十 µF，而且要 6.3V 低压档次；
2. 料号按通用规则解码：`HGC`(华瓷) + `0805`(尺寸) + `R5`(介质) + **`106`(=10µF)** + `K`(±10%) + **`250`(=25V)** + `NSLJ`。同表 No.2 的 `1210B106K500NT` 用的是同一套规则（`B`=X7R、`106`=10µF、`500`=50V），可互证 → **这颗是 10µF / 25V**。
   （说明：本次**外网搜索仍被限流**（Firecrawl 429，retry_after ≈ 58057 s ≈ 16 h），**未能在立创商城页面逐字复核该料号**，以上是**料号规则解码 + 封装上限**两条独立证据，不是页面原文。）
3. **`C11` 挂在 `24V` 母线上**（网表第 55 行）。**25V 耐压用在 24V 上 = 没有裕量**（常规要求 ≥1.5–2×），加上 MLCC 的直流偏压衰减，属于**上电随时可能裂/击穿短路**的器件 —— **必须改**。
4. `C15/C16` 挂在 `VOUT`(5V)：**耐压够（25V 对 5V = 5× 裕量）→ 这两颗的"件"本身没错，不需要换**。但图上值写 `470µF`、实际件是 10µF，**文字对不上**，必须把值改成实际值，否则以后（打板／采购／报告）有人照 `470µF` 去买，会买回一颗塞不进 0805 的电解。
   **容量够不够？两条都算过 —— 够：**
   - **稳态纹波**：`VOUT` 上还有 C17–C20（22µF×4 ≈ 88µF），加 C15/C16 共 ≈**108µF 陶瓷**；`ΔV ≈ ΔI/(8fC)` = 1.98A/(8×200k×108µF) ≈ **12mV** ✅（陶瓷 ESR 比电解小两个数量级，稳态纹波只会更小）
   - **负载跳变（0→3A）**：这里不是靠电容硬扛，而是靠**电感电流爬升**：`di/dt = (Vin−Vout)/L` = 19V/10µH = **1.9A/µs** → 1.6µs 就补上 3A；电容只需补 `½·ΔI·t` = 2.4µC → 压降 = 2.4µC/108µF ≈ **22mV** ✅
   - ⚠️ **前提**：上面两个数都建立在 **C17–C20（4×22µF）必须装上** 之上（它们现在还是未选料 + `C0603` 占位）。**少了这 88µF**，108µF → 20µF，纹波变 ≈124mV、跳变压降变 ≈120mV —— 还是能跑，但差一个数量级。
5. 该行 **立创编号为空**，本来就没落地（也要手动挑）。

> **一句话分清**：**只有 `C11` 需要换"件"**；`C15/C16` 的件是好的，**要改的只是图上的值**（两个字）。
