```powershell
# ② 补图 / 批量改内容 → 放好图后重跑生成器：

# ③ 校验（页眉图片 / 页脚页码 / 版心 / 表格与插图宽度 / 章节齐备）：
& 'C:\Users\22431\.dsh\dsh-runtimes\dsh-primary-runtime\dependencies\python\python.exe' '校验.py'
```

> ⚠️ **重跑 `工具/生成脚本.py` 会覆盖 `技术文档-FPGA数字电源-20261012.docx`。**
> 所以：**已经用 Word 手工改过的文字/数据，重跑前先另存备份**（或把改动同步回脚本）✅
