# sim/ — DPWM 自检回归测试台

一条命令验证 DPWM 的五项硬指标，**不用打开波形也能判断过没过**：每条检查自己打印 `[ OK ]` / `[FAIL]`，最后给总结。

## 怎么跑

**方式一：批处理（推荐，约 20 秒出结果）**

双击 `run_sim.bat`（需要 Vivado 2022.2 的 xsim，脚本里 `VIVADO_BIN` 默认 `D:\Xilinx\Vivado\2022.2\bin`，装在别处就改这一行）。

**方式二：命令行**

```bat
cd 03-FPGA工程\sim
xvlog ..\rtl\dpwm_core.v tb_dpwm.v
xelab -debug typical tb_dpwm -s tb_dpwm_sim
xsim tb_dpwm_sim -runall
```

**方式三：Vivado 图形界面（看波形用）**

1. Create Project → RTL Project，器件选 `xc7z020clg400`；
2. 把 `..\rtl\dpwm_core.v` 加为设计源，`tb_dpwm.v` 加为仿真源（勾 "Add as simulation source"）；
3. SIMULATION → Run Simulation → Run All；
4. 波形窗口里把 `pwm_h`、`pwm_l`、`period_tick` 拖出来，用标尺量一遍——这就是报告里的原始素材。

## 五项验收标准

| # | 检查什么 | 期望值 | 为什么要检查 |
| --- | --- | --- | --- |
| 1 | 开关周期 | 5000 ns（200.0 kHz） | 周期错了，后面所有计算全错 |
| 2 | 分辨率 | duty +1 → 高电平 +5 ns | 分辨率不够会出现极限环（输出永远小幅振荡） |
| 3 | 死区 | 200 ns（上管关→下管开、下管关→上管开，两个方向都量） | 死区太短会直通炸管；太长会失真、效率下降 |
| 4 | 互补关系 | 上管 + 下管 + 2×死区 = 一个周期 | 高侧/低侧时间账必须对得上 |
| 5 | 故障封锁 | `fault_i = 1` → 两路立即同时为低 | 保护链路最后一环，宁停不停错 |

测试台另有一条**全程监视**：任何瞬间 `pwm_h` 与 `pwm_l` 同时为高就立刻 `[FAIL]` 并计数（这是硬件红线，直通会烧 MOS）。

## 当前实测输出（上板版 RTL，2026-10-30 复跑）

```
 DPWM 验收测试台  |  周期 5000 ns  |  死区 200 ns
[ OK ] 验收1 开关周期：5000.00 ns  →  开关频率 200.0 kHz
       实测高电平：duty=500 → 2300.00 ns；duty=501 → 2305.00 ns
[ OK ] 验收2 分辨率：duty+1 → 高电平 +5.00 ns（正好 1 个时钟）
[ OK ] 验收3 死区（上管关 → 下管开）：200.00 ns
[ OK ] 验收3 死区（下管关 → 上管开）：200.00 ns
[ OK ] 验收4 互补关系：上管 2300.00 + 下管 2300.00 + 2×死区(=2×200) = 5000.00 ns
[ OK ] 验收5 故障封锁：fault_i=1 → 两路同时为低
 结果：全部通过
```

> 说明：`duty=500` 对应高电平 2300 ns = (500 − 40) × 5 ns，即死区占的 40 个计数算作低电平——这与上板实测的高侧脉宽口径一致。
